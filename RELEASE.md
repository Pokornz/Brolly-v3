## Release scope

This public release promotes the approved work through private review build v3.2.53. It includes reliability and battery-efficiency improvements, rolling future forecast mapping, defensive weather parsing, corrected sunrise and sunset selection with marker-grid placement, validated persisted settings, fixed complication lanes, expanded number-visibility controls, revised font-size ladders, rebuilt geometric Roman Sans numerals, retained Roman Serif numerals, original Brolly GPath weather icons, custom-location confirmation, and the cleaned-up versioned settings interface. Weather icon sizing now defaults to Custom at Size 3, while the alternative matching mode is labelled “Match number size (beta).”

The release preserves UUID `53a30793-7406-44e0-b02e-35fad4314fc5` and supports Aplite, Basalt, Chalk, Diorite, Emery, Flint, and Gabbro.
